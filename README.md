# Neon Tetris

A small, dependency-free Tetris game built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or start any static server from this directory:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Controls

- Arrow keys: move and rotate
- Space: hard drop
- `P`: pause
- Touch controls are available on small screens
